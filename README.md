# InomTechs Website

Corporate website for InomTechs, built with React, TypeScript, Vite, Tailwind CSS, Motion, and i18next.

## Run locally

Requirements: Node.js 20+ and npm.

```bash
npm install
npm run dev
```

The development server runs on `http://localhost:3000`.

## Quality checks

```bash
npm run lint
npm run build
```

## Production

The site is configured as a Vite SPA. Before deployment, verify the production domain in `index.html`, `public/robots.txt`, and `public/sitemap.xml`.
